## ESPECIFICACIONES TÉCNICAS

### Video (Reels/Stories Ads)
| Especificación | Valor |
|---|---|
| Formato recomendado | Vertical 9:16 |
| Resolución mínima | 1080 x 1920 px |
| Duración óptima | 15-30 segundos |
| Duración máxima | 60 segundos |
| Peso máximo | 4 GB |
| Formatos | MP4, MOV |
| Audio | Siempre con subtítulos (70% sin sonido) |

### Imagen (Feed/Story Ads)
| Especificación | Valor |
|---|---|
| Feed | 1080 x 1080 px (cuadrado) o 1080 x 1350 px (vertical) |
| Story | 1080 x 1920 px |
| Texto en imagen | Máximo 20% de la imagen |
| Formato | JPG, PNG |

### Texto del anuncio
| Campo | Caracteres recomendados |
|---|---|
| Texto principal | 125 caracteres (antes del "ver más") |
| Título | 40 caracteres |
| Descripción | 30 caracteres |
| CTA | Usar botones nativos de Meta |

## ESTRUCTURA DE CAMPAÑA PARA SEGUROS

### Nivel Campaña
```
Objetivo: Lead Generation (formulario) o Messages (WhatsApp)
Presupuesto: Por campaña, no por conjunto de anuncios
Categoría especial: SÍ — "Crédito, empleo, vivienda y seguros"
```

### Nivel Conjunto de Anuncios (Ad Set)
```
Ubicación: Texas — ciudades específicas si hay presupuesto bajo
  Prioridad: Houston, San Antonio, Dallas-Fort Worth, Austin, El Paso
Idioma: Español
Edad: 35-65 años (para final expense), 30-55 (seguros de vida general)
Género: Todos
Dispositivos: Solo móvil (90% del tráfico hispano)
```

### Segmentación por Intereses (combinar 2-3)
**Bloque 1 — Seguros directos:**
- Life Insurance
- Health insurance
- Insurance (seguros)

**Bloque 2 — Comunidad hispana:**
- Telemundo, Univision, Estrella TV
- Comida Latina, Quinceañeras
- Remesas, Western Union, Zelle
- Fútbol soccer (alta afinidad hispana)

**Bloque 3 — Comportamiento financiero:**
- Pequeños negocios, Self-employed
- Homeowners (dueños de casa)
- Padres con hijos en el hogar

### Exclusiones recomendadas
- Menores de 30 años (bajo poder adquisitivo para seguros)
- Audiencias que ya convirtieron (usar exclusión de custom audience)

## AUDIENCIAS PERSONALIZADAS (Custom Audiences)

### Crear estas audiencias:
1. **Visitantes del perfil de Instagram** (últimos 90 días)
2. **Quienes vieron 50%+ de tus videos** (últimos 60 días)
3. **Lista de clientes actuales** (subir CSV con emails/teléfonos)
4. **Quienes enviaron DM** (últimos 90 días)

### Lookalike Audiences (después de tener 100+ conversiones):
- Lookalike 1% de clientes actuales — Texas
- Lookalike 1-3% de quienes vieron videos — Texas

## FASES DE CAMPAÑA

### FASE 1 — CALENTAMIENTO (Semana 1-2)
```
Presupuesto: $5-10/día
Objetivo: Video Views o Reach
Audiencia: Fría (intereses)
Creativo: Reel educativo 30 seg — no pedir nada
Métrica clave: CPV (costo por vista) menor a $0.05
Propósito: Construir audiencia cálida para retargeting
```

### FASE 2 — CAPTACIÓN DE LEADS (Semana 3-4)
```
Presupuesto: $15-25/día
Objetivo: Lead Generation (formulario nativo)
Audiencia: Retargeting — quienes vieron 50%+ del video de Fase 1
Creativo: Historia de cliente + CTA directo
Formulario (en español):
  - Nombre completo
  - Número de WhatsApp
  - Edad (desplegable: 30-40, 41-50, 51-60, 61+)
  - "¿Actualmente tienes seguro de vida?" (Sí / No / No sé)
Métrica clave: CPL menor a $15
```

### FASE 3 — CONVERSIÓN DIRECTA (Mes 2+)
```
Presupuesto: $10-15/día
Objetivo: Messages → WhatsApp
Audiencia: Lookalike de clientes, 1%, Texas
Creativo: Video testimonial o autoridad (20 años de experiencia)
Métrica clave: Costo por conversación iniciada menor a $8
```

## COMPLIANCE OBLIGATORIO PARA SEGUROS EN META

### SIEMPRE incluir:
- "Sujeto a aprobación"
- "Términos y condiciones aplican"
- Tu número de licencia de agente (recomendado)

### NUNCA escribir:
- "Garantizado" o "100% aprobado"
- "Sin requisitos médicos" (a menos que sea literalmente verdad para ese producto)
- Montos específicos de beneficio sin disclaimer
- "El mejor seguro" sin evidencia

### Configuración de cuenta de Meta:
- Activar categoría especial de "Crédito, empleo, vivienda y seguros"
- Sin esta configuración, Meta puede rechazar anuncios o cerrar cuenta
